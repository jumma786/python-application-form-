# 📋 Application Form GUI (Python Tkinter)

A simple Python GUI Application Form built using Tkinter that collects user information, course details, and registration status. The program validates required fields and prints the submitted data to the console.

This project demonstrates Python GUI development, user input handling, and form validation.

## 🚀 Features

Graphical User Interface using Tkinter

User Information Form

Course Registration Details

Dropdown selection using Combobox

Number input using Spinbox

Form validation (required fields)

Terms & Conditions confirmation

Warning messages using MessageBox

## 🖥️ Application Interface

The form includes three main sections:

##### 1️⃣ User Information

First Name

Last Name

Title (Mr, Ms, Dr)

Age

Nationality

Gender

##### 2️⃣ Course Information

Registration Status

Number of Completed Courses

Number of Semesters

##### 3️⃣ Terms & Conditions

Users must accept the terms before submitting the form.
